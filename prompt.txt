问题：SFT脚本训练loss为0
之前直接参考GRPO的训练脚本，在训练SFT时指定数据集注册参数为--custom_register_path dataset/dataset_emo_omni_full_grpo.py \
但是SFT训练完后，发现loss为0，没有正常训练。

经过分析，原因可能是：
- labels 被全部屏蔽（Masked Out）：将所有的 labels 都设置为了 -100（或者在该框架中被定义为不计算 loss 的 token），那么 Loss 就会始终为 0
- 数据集注册脚本的逻辑错误：custom_register_path中Text 字段缺失：检查返回的字典中是否包含 response 或 output 字段。脚本内容与ms-swift的键值冲突

经过检查，发现是数据集注册脚本的逻辑错误，返回的字典中缺少 response 字段。脚本内容与ms-swift的键值冲突。

ms-swift框架中，GRPO的训练样本的键值要求为query和solution，对应的我们使用的是/train/dataset/dataset_emo_omni_full_grpo.py：    

        row = {
                'query': instruction,
                'solution': answer,
                'videos': [video_path],
            }
但是之前为了方便，在训练SFT脚本时，直接注册了已有的数据集文件--custom_register_path dataset/dataset_emo_omni_full_grpo.py \，导致键值冲突。ms-swift框架中，SFT的训练样本的键值要求为query和response,新建/train/dataset/dataset_emo_omni_full_sft.py文件，将键值修改为response。 ：

row = {
                'query': instruction,
                'response': answer,
                'videos': [video_path],
            }
并创建新的train/script_train/Train_SFT.sh，注册数据集为--custom_register_path dataset/dataset_emo_omni_full_sft.py \

成功训练，loss正常。
